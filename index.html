Architecture

不是三个模型轮流聊天，而是一套有职责边界的研发组织。

规格定义目标，Brain 做判断，Executor 做执行，Verification 给证据，人类保留关键控制权。

Specification

Spec Kit

把需求、约束与验收标准变成稳定规格，减少长任务依赖临时上下文猜测。

Task Contract

Task 01–99

把复杂目标拆成有稳定身份、明确边界、可追踪且可验收的研发任务。

Reasoning

GPT · Brain / Reviewer

理解任务事实、判断下一步、审查执行证据，并决定继续、修订、暂停或完成。

Execution

Claude Code / Codex · Executor

真正读取仓库、修改文件、增加测试、运行允许命令并返回执行证据，但无权自行降低验收标准。

Control Plane

Verification · Approval · Recovery

确定性校验事实，在关键节点保留人类控制，并让中断任务从可信进度继续。

Spec 是施工图，Task 是工单，GPT 是技术负责人 / Reviewer，Claude Code / Codex 是执行工程师，Guardian 负责把这一切组织成可靠闭环。

Human-in-the-loop

不是让人一直盯着 AI，而是在真正需要判断时把人叫回来。

Human Required → 自动邮件通知开发者

当任务进入审批 / 驳回、人工 continuation、高风险动作或无法安全自动裁决的关键节点，NovaWing 会先保存当前 Session / checkpoint，安全暂停自动执行，并自动发送邮件通知开发者。

Human Required → Persist Session / Checkpoint → Suspend Automation → Email Developer → Explicit Human Decision → Resume Existing Session → Verification / Review

邮件只是注意力路由，不是权限提升。开发者允许继续后，原 Goal、Constraints、Acceptance Criteria、Allowed Paths 与 Forbidden Paths 仍然有效。
